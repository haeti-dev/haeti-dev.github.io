# 디자인 시스템

블로그(wasm)와 어드민(JVM)이 함께 쓰는 디자인 규칙입니다. 토큰은 `core:designsystem`, 조합 컴포넌트는 `core:ui`,
글 본문 렌더링은 `core:markdown`에 있습니다. 이 문서의 값은 모두 코드에 있는 값 그대로입니다.

## 원칙

**바탕은 조용하게, 색은 정보에만 씁니다.** 바탕과 글자는 차가운 뉴트럴 회색으로 두고, 채도가 있는 색은 카테고리에만
씁니다. 독자가 칩, 필터, 커버, 읽기 진행 바의 색만 보고 "이 글이 어디에 속하는가"를 알 수 있게 하려는 것입니다.

**브랜드 색은 상호작용 표시에만 씁니다.** 파랑은 워드마크의 `.log`, 활성 메뉴 밑줄, 언어 토글, 링크 호버, 포커스 링,
인라인 코드에만 씁니다.

**글마다 대표 그림이 있습니다.** 목록에 그림이 없으면 블로그보다 문서 목록처럼 보입니다. 프론트매터에 `thumbnail`이 있으면
그 이미지를 쓰고, 없으면 카테고리 색으로 코드 미니맵을 그립니다. 미니맵은 글 slug를 시드로 써서 같은 글은 항상 같은
모양이 나옵니다. 링크 미리보기(OG) 이미지도 빌드 때 같은 방식으로 그립니다.

**움직임은 최소로 둡니다.** 상시 애니메이션은 없습니다. 호버나 선택처럼 상태가 바뀔 때만 색이 짧게 전환되고,
글을 열 때 제목이 한 번 올라옵니다. 화면을 옮기면 이전 화면은 바로 사라지고 새 화면만 짧게(150ms) 나타나며,
늦게 도착한 이미지와 본문도 짧게(180ms) 나타납니다. 두 화면이 겹치거나 내용이 툭 튀어나와 깜빡여 보이지 않게
하려는 것입니다. 클릭 리플은 쓰지 않고, 로딩은 스피너 대신 최종 레이아웃 모양의 스켈레톤으로 보여 줍니다.
스켈레톤은 로딩이 150ms를 넘길 때만 띄워, 이미 읽어 둔 글에서 한 번 번쩍이지 않게 합니다.

**코드는 페이지 테마와 관계없이 다크 카드로 보여 줍니다.** 색은 JetBrains IDE의 다크 테마 팔레트를 따르고,
라이트 페이지에서도 코드 카드는 바뀌지 않습니다.

### 카테고리

카테고리마다 진한 accent와 연한 tint 한 쌍을 씁니다. accent는 칩의 점과 글자, 선택된 필터의 바탕, 읽기 진행 바에 쓰고, tint는 커버 바탕에 씁니다.

| 카테고리 | accent (L / D) | tint (L / D) |
|---|---|---|
| 안드로이드 | `#138A5E` / `#4CC995` | `#E3F4EC` / `#15302A` |
| 코틀린 | `#6D4CE8` / `#A48CFF` | `#EEEAFD` / `#262043` |
| 컴포즈 | `#2563D9` / `#70A0FF` | `#E6EEFD` / `#16263F` |
| 회고 | `#B97709` / `#F0B43C` | `#FBF0DA` / `#35290F` |
| 웹 | `#CF3A6E` / `#FF7FA8` | `#FCE7EF` / `#3A1A27` |
| (대체용) Teal | `#0E8395` / `#4CC6D8` | `#E0F3F6` / `#132F35` |

표에 없는 카테고리 이름은 이름의 해시로 Teal, Rose, Blue, Violet, Green, Amber 중 하나에 고정 배정합니다. 새 카테고리를
추가할 때 코드를 고치지 않아도 색이 붙고, 새로고침해도 색이 바뀌지 않습니다. 정의는 `CategoryPalette.kt`에 있고,
빌드 때 OG 이미지를 그리는 `OgCover.kt`가 같은 값을 씁니다.

콜아웃(`[!note]`, `[!tip]`, `[!warning]`)은 각각 파랑, 초록, 주황 계열의 왼쪽 막대(4dp)와 연한 바탕을 씁니다.

## 글꼴

번들 폰트는 Pretendard(400, 700)와 JetBrains Mono(400) 두 종류입니다. Kotlin/Wasm은 캔버스에 직접 그리기 때문에
시스템 폰트를 쓸 수 없고, 한글 폰트는 무거워서 종류와 굵기를 최소로 줄였습니다. 고정폭 글꼴은 코드에만 씁니다.

## 레이아웃

| 항목 | 값 |
|---|---|
| 글 본문 컬럼 | 최대 760dp (17sp 본문 기준 한 줄 45자 안팎) |
| 홈과 목록 컬럼 | 최대 880dp (썸네일이 붙는 만큼 넓게) |
| 글 상세 커버 | 홈 컬럼 폭(880dp)으로 본문보다 넓게 |
| 좌우 패딩 | 600dp 미만 20dp, 그 외 24dp |
| 상단바 아래 여백 | 840dp 이상 80dp, 그 미만 40dp |
| 상단바 | 높이 72dp, 아래 헤어라인. 600dp 미만은 60dp 행과 40dp 메뉴 행 |

화면 구간은 `LayoutTier` 하나로 정합니다. 뷰포트 폭은 앱 셸에서 한 번만 재고, 하위 컴포넌트는
`LocalLayoutTier`를 읽기만 합니다.

| 구간 | 폭 |
|---|---|
| Compact | 600dp 미만 |
| Single | 600 ~ 840dp |
| Desktop | 840 ~ 1200dp |
| Wide | 1200dp 이상 |

### 커버와 모서리

| 위치 | 비율 | 모서리 |
|---|---|---|
| 홈의 최신 글 | 2.4:1 (600dp 미만 16:10) | 24dp |
| 글 상세 | 2.2:1 (600dp 미만 16:10) | 24dp (600dp 미만 16dp) |
| 목록 썸네일 | 168×112dp (600dp 미만 88×66dp) | 14dp |

그 밖의 모서리는 크기에 따라 나눕니다. 코드 카드, 이전/다음 글 카드, 유튜브 임베드는 16dp, 콜아웃과 검색창은 12dp,
포커스 링과 스켈레톤, 복사 버튼은 8dp, 카테고리 필터는 알약 모양입니다.

## 상호작용

모든 클릭 요소는 `Modifier.haetiClickable` 하나를 씁니다.

- 클릭 리플이 없습니다(`indication = null`).
- 마우스를 올리면 커서가 손 모양으로 바뀝니다.
- 테마 토글 같은 아이콘 버튼은 호버하면 `hover` 토큰 바탕이 150ms 동안 페이드됩니다.
- 글 목록과 최신 글은 바탕 대신 제목 색이 카테고리 accent로 바뀝니다(160ms). 목록 행은 켜질 때만 페이드하고
  꺼질 때는 바로 돌립니다. 꺼질 때도 페이드하면 목록을 빠르게 훑을 때 이전 행이 남아 두 행이 함께 칠해지기 때문입니다.
- 포커스 링(2dp, 모서리 8dp)은 키보드로 이동했을 때만 그립니다. 마우스 클릭으로 생긴 포커스에는 그리지 않습니다.
- 링크는 평소 연한 밑줄이 있고, 호버하면 밑줄이 brand 색으로 바뀝니다.

글 상세에서는 상단바 바로 아래에 3dp 높이의 읽기 진행 바가 카테고리 accent 색으로 표시됩니다.

## 코드 표시

코드 카드는 배경 `#232329`, 모서리 16dp, 안쪽 여백 20dp입니다. 글자는 14sp(600dp 미만 13sp)입니다.
오른쪽 위에 언어 라벨(13sp)과 복사 버튼(아이콘 16dp, 누를 수 있는 영역 30dp)이 있고, 복사가 끝나면 체크 아이콘으로 바뀝니다.

## 테마와 언어

- 첫 방문에는 시스템 다크 모드 설정을 따르고, 상단바 토글로 바꾼 값은 `localStorage`(`haeti.theme`)에 저장합니다.
  테마가 바뀌어도 토큰만 바뀌고 레이아웃은 그대로입니다.
- 상단바의 `KO | EN` 토글로 화면 문구와 글을 영어로 바꿉니다. 첫 방문에는 브라우저 언어를 따르고, 선택은
  `haeti.lang`에 저장합니다. 번역본이 없는 글은 원문과 함께 "only available in Korean" 안내를 보여 줍니다.
- 글 속 그림은 이미지 지시어의 `dark` 속성으로 다크 모드용 이미지를 따로 지정할 수 있습니다.
  README와 문서, 글에 넣는 다이어그램은 `design/diagrams`에서 같은 토큰과 글꼴로 라이트/다크 두 장을 만듭니다.

## 어드민

어드민도 같은 `HaetiTheme`과 토큰을 씁니다. 미리보기는 블로그의 마크다운 렌더러와 카테고리 칩, 메타 줄, 커버 컴포넌트를
그대로 재사용하기 때문에, 어드민에서 본 본문과 배포된 본문이 같습니다.
